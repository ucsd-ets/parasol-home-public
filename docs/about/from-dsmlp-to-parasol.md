<p class="lead">PARASOL is the new name for DSMLP, the Data Science and Machine Learning Platform, and it takes in the research work that ran as the Research Cluster. If you used DSMLP or Datahub before, you do not need to do anything. Your account, your files, and your commands work as before.</p>

<dl class="docs-glance">
<div><dt>What you need to do</dt><dd>Nothing</dd></div>
<div><dt>Login node</dt><dd><code>dsmlp-login.ucsd.edu</code></dd></div>
<div><dt>Reservation app</dt><dd><a href="https://reserve.dsmlp.ucsd.edu/">reserve.dsmlp.ucsd.edu</a></dd></div>
<div><dt>Support</dt><dd><a href="mailto:parasol@ucsd.edu">parasol@ucsd.edu</a>, research work included; Research IT also at <a href="mailto:rcd-support@ucsd.edu">rcd-support@ucsd.edu</a></dd></div>
</dl>

## What Stays the Same

| You use | It is still |
|---|---|
| Datahub in a browser | [datahub.ucsd.edu](https://datahub.ucsd.edu), with your UC San Diego sign-in |
| The login node | `dsmlp-login.ucsd.edu` |
| The reservation app | [reserve.dsmlp.ucsd.edu](https://reserve.dsmlp.ucsd.edu/) |
| Launch scripts | `launch.sh`, `launch-scipy-ml.sh`, and the other launch commands, with the same flags |
| Your files | The same home directories, shared workspace space, and datasets |
| Workspaces and quotas | The same course, lab, and project workspaces, with the same limits |
| The ITS Service Desk | [support.ucsd.edu](https://support.ucsd.edu/) |
| Research IT, for research work | [rcd-support@ucsd.edu](mailto:rcd-support@ucsd.edu), alongside [parasol@ucsd.edu](mailto:parasol@ucsd.edu) |
| Policy | The same conditions of use, in [Policy](../reference/policy.md) |

> [!NOTE]
> **You will still see the old name**
> Hostnames, container labels, and system messages still say `dsmlp`. Command
> output on the cluster also uses the old name. Both names refer to the same
> platform.

## Where the Old Documentation Went

Each page of the DSMLP documentation has a matching page here, at the same
address. The [Documentation](../docs/README.md) index keeps the same seven
topics, and the audience guides are under [Get Started](../get-started/README.md).

| DSMLP documentation | PARASOL page |
|---|---|
| Overview | [How PARASOL Works](../overview.md) |
| Teaching with Datahub and DSMLP | [Teaching with Datahub and PARASOL](../instructor-or-ta.md) |
| Research on DSMLP | [Research on PARASOL](../individual-researcher.md) |
| Other audience guides | The same titles under [Get Started](../get-started/README.md) |
| Technical documentation | The same titles under [Documentation](../docs/README.md) |

When the DSMLP documentation site is retired, each of its addresses will
forward to the same address here, so course materials that link to the old
addresses keep working.
