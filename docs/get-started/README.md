<p class="home-kicker">New in Winter 2027</p>
<h2 id="start-open-learning-heading">Open Learning</h2>
<p>From Winter 2027, students in eligible majors and programs have an Open Learning workspace for coursework and exploration outside a course workspace or a sponsored project. You are added from your major or program, so there is nothing to request. Most tasks need only a browser.</p>
<p>In peak weeks, coursework comes first and Open Learning has lower GPU limits. If a course will need substantial GPU time then, ask the instructor to request it for the course.</p>
<p><a class="btn btn-primary" href="/open-learning/">Start with Open Learning</a></p>
</div>
<div class="col-md-5 hub-split-media">
<aside class="dsmlp-resource-panel" aria-labelledby="start-open-learning-programs-heading"><p class="home-kicker">Eligible programs</p><h3 id="start-open-learning-programs-heading">Who Has Open Learning</h3><ul><li><a href="/open-learning/#eligible-programs">Halıcıoğlu School Affiliates</a></li></ul><p>The Data Science and Artificial Intelligence majors, the Data Science minor, and the data science master's and Ph.D. programs. Other schools can offer Open Learning to their students. The Halıcıoğlu School's Open Learning workspace draws on the School's own GPU capacity, alongside its courses and research. If your program is not listed and you would use it, tell your dean's office.</p></aside>

<section class="hub-section hub-section-sand" aria-labelledby="start-first-heading">
<div class="hub-heading"><p class="home-kicker">Before your first session</p><h2 id="start-first-heading">Rules That Apply to Everyone</h2></div>
<div class="row hub-number-grid hub-number-grid-light">
<div class="col-sm-6 col-md-3"><article><span>01</span><h3>Root Access</h3><p>Containers run as you, without sudo. Install packages in your own environment. See <a href="/environments/customizing-your-environment/">Customizing an Environment</a>.</p></article></div>
<div class="col-sm-6 col-md-3"><article><span>02</span><h3>The Login Node</h3><p>The login node only launches jobs and moves files. Run your work in a session. See <a href="/access/the-login-node/">The Login Node</a>.</p></article></div>
<div class="col-sm-6 col-md-3"><article><span>03</span><h3>Service Units for GPUs</h3><p>Booked or on demand, a GPU session draws on your workspace's Service Unit budget. See <a href="/gpu-access/service-units-and-budgets/">Service Units &amp; Budgets</a>.</p></article></div>
<div class="col-sm-6 col-md-3"><article><span>04</span><h3>Idle GPU Sessions</h3><p>A session that sits idle long enough is stopped. Save work as you go. See <a href="/gpu-access/what-ends-a-session/">What Ends a Session</a>.</p></article></div>
</div>
